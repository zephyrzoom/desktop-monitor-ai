# 2026-11-12

## fix: 日报分析期间恢复「正在分析」提示并禁止重复触发

- 现象：日历选某天点分析后看不到「正在分析」，还能继续点其它日期发起分析。
- 根因：分析状态由前端各次 `triggerAnalysis` 的 `await ... finally` 独立维护；
  Rust 命令用 `try_begin_analysis()` 做互斥，重复点击 / 定时分析占用时会立刻返回
  `{"status":"busy"}`，该次调用的 `finally` 随即把全局 `analyzing` 清成 false，
  于是后端仍在分析但界面没有任何提示，且所有按钮重新可点。
- 后端改为唯一事实来源：`runtime.rs` 用 `Mutex<Option<AnalysisStatus>>` 记录
  `{kind, target}`（daily/rerun/summary/scheduled），`begin_analysis` /
  `end_analysis` 成对发出 `analysis:started` / `analysis:finished`；
  新增 `analysis_status` 命令供窗口重载后同步（已在 lib.rs 注册）。
  三类命令与定时任务 `run_scheduled` 统一接入。
- 前端：`AnalysisContext` 只镜像后端状态（started/finished + 挂载时查询），
  用 `busyRef` 在同一帧内也拦住重复触发；提供 `busy` / `busyLabel`，
  原有 `analyzing` / `rerunning` / `generating` 全部由 kind 派生。
- 界面：日报进度面板移到页面顶部并显示正在分析的日期；日历给该日期加转圈标记，
  分析期间锁定日期切换与所有分析/补算/汇总按钮；侧边栏增加全局「正在分析」提示
  （任何页面都可见），窄屏保留转圈图标。
- 验证：`npm run typecheck`、`cargo check`、`npm run build:web`、prettier 均通过；
  eslint 剩余报错为改动前既有的 `react-hooks/immutability`（useEffect 中调用后面声明的函数）。

## fix: 分析期间只锁「发起分析」入口，恢复日报浏览

- 反馈：上一版连日历和「已分析」胶囊一起禁用，分析时没法查看其它日期的日报。
- 调整：`DatePicker` 去掉 `disabled` 属性（保留 `analyzingDate` 的转圈标记），
  日报页日期切换与胶囊恢复可点；`busy` 只用于禁用「分析这一天 / 重新分析 /
  批量补算 / 立即分析 / 生成汇总」这类会再次触发分析的按钮，并清掉多余的 `:disabled` 样式。
- 原则：分析状态只影响「能否发起新任务」，不影响浏览与阅读已有内容。

## feat: 正在分析的任务支持手动取消

- 需求：分析任务可手动终止，不必等一批 LLM 请求跑完。
- 后端取消原语：`runtime.rs` 增加 `cancel_tx: watch::Sender<bool>`
  （用 watch 而非 AtomicBool，await 中的请求能被立即唤醒且不丢通知）；
  `request_cancel()` 给状态打 `cancelling` 标记并广播 `analysis:cancelling`，
  `wait_cancelled()` 供请求层等待，`begin/end_analysis` 负责复位信号。
  新增命令 `analysis_cancel`（无任务时返回 `idle`），已在 lib.rs 注册。
- 请求层：`analyzer/llm.rs::chat` 用 `tokio::select!` 把 HTTP 请求（含重试等待）
  与 `wait_cancelled()` 竞速，取消时立刻 drop 请求并返回 `CANCELLED`。
- 分析层：`analyzer::CANCELLED` + `is_cancelled_error()` 区分取消与真失败；
  `analyze_daily` 在每批/合并/记忆/总结/落库前设检查点（取消不写半成品）；
  `rerun_daily` 逐日检查并返回 `cancelled`（已完成日期保留）；
  `backfill_range` 与 `run_scheduled` 在步骤间检查并跳过后续阶段。
- 命令返回：单日/汇总返回 `status: "cancelled"`，批量补算额外带 `cancelled` 字段。
- 前端：`AnalysisContext` 新增 `cancelling` / `cancelAnalysis`，订阅
  `analysis:cancelling`；`ProgressPanel` 增加取消按钮（取消中禁用），
  日报/今日/季度/年度页均接入；侧边栏全局指示器也可直接取消；
  批量补算被取消时提示「已取消：完成 X/Y 天，已完成的部分已保存」。
- 验证：`npm run typecheck`、`cargo check`、`npm run build:web` 通过；
  eslint 仅剩改动前既有报错。
