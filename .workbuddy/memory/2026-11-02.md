# 2026-11-02

## 季度/年度汇总支持复制

- 新增 `src/renderer/src/lib/clipboard.ts`：`copyText()` 先走 `navigator.clipboard`，
  失败或不可用（macOS 下 `tauri://` 协议可能拒绝）退回 textarea + `execCommand('copy')`。
- 新增 `src/renderer/src/lib/summary-text.ts`：把汇总 JSON 拼成可粘贴的纯文本。
  - `buildQuarterlySummaryText`：`2026 年第一季度工作汇总` + 【概述】/【工作亮点】/【工作分类统计】。
  - `buildYearlySummaryText`：`2026 年度工作总结` + 开头段 + `一、二、`分类（`1）`条目）+【总结】。
  - 注意标题拼接别再重复「季度/年度」字眼，`formatQuarterLabel` 已含「第一季度」。
- 新增 `src/renderer/src/components/CopyButton.tsx`：2 秒内显示「已复制」/「复制失败」，
  `text` 为空时禁用；`unmount` 时清理定时器。
- 两个汇总页把「生成」按钮和复制按钮放进同一个 flex 行，复制按钮仅在已有结果时出现。
- `globals.css` 补 `.button:disabled`（opacity .55 + not-allowed），此前全局没有禁用态样式。

- `summary-text.ts` 重构为「分节 + 整篇」两层导出：
  - 季度：`buildQuarterlyOverviewText` / `buildQuarterlyHighlightsText` /
    `buildQuarterlyCategoryText` / `buildQuarterlyFullText`

    `buildYearlyConclusionText` / `buildYearlyFullText`

    `buildQuarterlySummaryText` / `buildYearlySummaryText` 已改名为 `*FullText`。

  成功后换成对勾并加 `.copied` 变绿），文字按钮与图标按钮共用同一套状态逻辑。
- 样式：`.card-title` 改为 flex 两端对齐以承载右侧图标；新增 `.copy-icon-button`、
  `.summary-box.has-copy`（`position: relative` + `padding-right: 54px`，
  图标绝对定位在右上角），用于无标题的「概述/开头语/总结」区块。
