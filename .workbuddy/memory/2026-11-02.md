# 2026-11-02

## 季度/年度汇总支持复制

- 新增 `src/renderer/src/lib/clipboard.ts`：`copyText()` 先走 `navigator.clipboard`，
  失败或不可用（macOS 下 `tauri://` 协议可能拒绝）退回 textarea + `execCommand('copy')`。
- 新增 `src/renderer/src/lib/summary-text.ts`：把汇总 JSON 拼成可粘贴的纯文本。
  - `buildQuarterlySummaryText`：`2026 年第一季度工作汇总` + 【概述】/【工作亮点】/【工作分类统计】。
  - `buildYearlySummaryText`：`2026 年度工作总结` + 开头段 + `一、二、`分类（`1）`条目）+【总结】。
  - 注意标题拼接别再重复「季度/年度」字眼，`formatQuarterLabel` 已含「第一季度」。
- 新增 `src/renderer/src/components/CopyButton.tsx`：2 秒内显示「已复制」/「复制失败」，
  `text` 为空时禁用；`unmount` 时清理定时器。
- 两个汇总页把「生成」按钮和复制按钮放进同一个 flex 行，复制按钮仅在已有结果时出现。
- `globals.css` 补 `.button:disabled`（opacity .55 + not-allowed），此前全局没有禁用态样式。

## 各板块分节复制（同日追加）

- `summary-text.ts` 重构为「分节 + 整篇」两层导出：
  - 季度：`buildQuarterlyOverviewText` / `buildQuarterlyHighlightsText` /
    `buildQuarterlyCategoryText` / `buildQuarterlyFullText`
  - 年度：`buildYearlyOpeningText` / `buildYearlyCategoryText(category, index)` /
    `buildYearlyConclusionText` / `buildYearlyFullText`
  - 整篇文本 = 分节文本用 `\n\n` 拼接，避免两处格式漂移；旧名
    `buildQuarterlySummaryText` / `buildYearlySummaryText` 已改名为 `*FullText`。
- `CopyButton.tsx` 抽出 `useCopyState()`，新增 `CopyIconButton`（内联 SVG 复制图标，
  成功后换成对勾并加 `.copied` 变绿），文字按钮与图标按钮共用同一套状态逻辑。
- 样式：`.card-title` 改为 flex 两端对齐以承载右侧图标；新增 `.copy-icon-button`、
  `.summary-box.has-copy`（`position: relative` + `padding-right: 54px`，
  图标绝对定位在右上角），用于无标题的「概述/开头语/总结」区块。
- 经验：`.summary-box` 没有标题栏，加复制入口用浮动图标，不改原有排版结构。

## UI 改版（new-ui 分支）

- 新建分支 `new-ui`（基于 `tauri`），提交 `feat(ui): 重做界面视觉、图标与导航结构`。
- 设计系统：`globals.css` 重写为「令牌 + 组件」两层；浅色为主，`prefers-color-scheme: dark`
  自动切换（深色下强调色拆成 `--accent` 填充 / `--accent-fg` 文字两枚，避免白字对比不足）。
- 图标：新增 `components/Icon.tsx`，手写 30 个 24×24 线性图标（stroke 1.8，currentColor），
  不引入图标库；`IconName` 联合类型做编译期校验。
- 导航结构：侧边栏由 5 个平行链接改为「概览 / 报告 / 系统」三组，带图标、品牌标识、
  底部版本徽章；窄窗口（<760px）自动收成图标栏。
- 交互优化：
  - 汇总页默认选中当前季度/年份（`currentQuarterLabel()` / `currentYearLabel()`），
    不再一进来就是「请选择」。
  - 配置页改为分区卡片 + `.form-grid`（双列）/`.form-grid-3`（auto-fit 四列）表单，
    底部 `.save-bar` 吸附保存条 + 未保存提示（`dirty` 状态）。
  - 进度面板只在「当前页正在处理的对象」上显示（`analyzingDate === today`、
    `generatingLabel === selectedQuarter`），避免跨页误显示。
- 复用组件：`PageHeader` / `ProgressPanel` / `Alert` / `EmptyState`。
- 原生 `input[type=date]` 的日历按钮用 `::-webkit-calendar-picker-indicator{inset:0;opacity:0}`
  隐藏并让整块区域可点，避免与外层图标重复。
- 视觉验证：`vite --port 5199` + Edge headless 截图（临时 `__dev-mock.ts` 造假数据，
  验证后已删除）；`--force-dark-mode` 可让无头浏览器命中暗色媒体查询。
- 已知：`npm run lint` 仍有 7 个 `react-hooks/*` 报错，与改版前完全一致（历史遗留：
  useEffect 调用后声明的 loader），本次未处理。
