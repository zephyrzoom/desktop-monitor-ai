## 修复 Windows 便携版开机自启动 ENOENT（e5e5015）
- 现象：用户 Windows 机器重启后自启动报 `Error: ENOENT ... Temp\<随机目录>\index.js`
- 根因：electron-builder portable 每次启动解压到 %TEMP%\<随机目录>（issue #8739）；旧版本曾把 process.execPath（临时 exe）注册进 Run 键，重启后临时目录被清理导致报错。此前 fa4166c 已改用 PORTABLE_EXECUTABLE_FILE，但用户注册表里残留旧条目
- 修复：新增 src/main/utils/autostart.ts，应用启动时读 HKCU\...\Run，删除指向旧位置的本应用条目；若配置开启自启动则用当前正确路径重注册（自愈）。handlers.ts 与 index.ts 接入
- 待办：需重新 build:win 打包并替换用户机器上的 exe；用户也可手动在任务管理器-启动里删掉旧条目后重新开启自启动
